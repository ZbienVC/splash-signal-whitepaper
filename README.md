# Splash Signal White Paper

The Splash Signal white paper (v3) as a single standalone HTML page. Splash Signal is an on-chain intelligence tool for Solana traders that turns live chain and market data into ENTRY, EXIT and WATCH signals.

## View

Open `index.html` in a browser. There is no build step and no dependencies apart from Google Fonts loaded over the network.

## Publish

Serve the folder as a static site (for example GitHub Pages from the repo root, or any static host).
